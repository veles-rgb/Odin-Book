# Odin-Book

Odin-Book is a full-stack social media application project built as part of [The Odin Project](https://www.theodinproject.com/). It features user authentication, profiles, posts, comments, likes, follow requests, and image uploads.

## Features

- Secure user registration and login
- JWT authentication with refresh tokens
- User profiles with customizable profile pictures
- Create, edit, and delete posts
- Image uploads for posts and profiles
- Comment and reply system
- Like posts and comments
- Follow request and follower system
- User search functionality
- Protected routes and authorization
- Frontend and backend validation
- Responsive interface

## Features Overview

### Authentication

- Account registration and login
- Password hashing with bcrypt
- Access and refresh token authentication
- Protected API endpoints

### Social Features

- Create and manage posts
- Comment and reply to discussions
- Like posts and comments
- Follow and unfollow users
- Follow request system for connecting users

### User Profiles

- Custom profile pictures
- User search
- Follower and following lists

### Media Support

- Cloudinary image hosting
- Profile image uploads
- Post image uploads
